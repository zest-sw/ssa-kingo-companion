# 챌린지스퀘어 조사 요약 (2026.10.08)

킹고 컴패니언이 챌린지스퀘어와 겹치지 않고 그 위에서 돌기 위한 근거를 모은 기록입니다. 로그인하지 않았고, 신청·찜·설문·설정 변경은 하지 않았습니다.

- 확인 시각: 2026-10-08 15:35~15:43 KST
- 근거 수준: 로그인 전 화면은 직접 관찰, 로그인 뒤 화면은 학생성공센터의 2026 학생용 매뉴얼(2026-08-28 게시) 기준이며 실제 화면으로 검증하지 못했습니다.
- 원자료: [`challenge-square-2026-10-08.json`](./challenge-square-2026-10-08.json)

## 접근 범위
- PC(`chsquare.skku.edu`)와 모바일(`chsquarem.skku.edu`) 모두 로그인 화면만 보입니다. 공개 프로그램 목록이 없습니다.
- `robots.txt`는 404(없음)였습니다. 그래도 몇 페이지만 열람했습니다.
- 공개 경로로는 학생성공센터 공지, 도전학기 표, SKKU 비교과 가이드가 있습니다. 비교과 가이드에는 2026.10.08 기준 참여 가능 프로그램이 학부 61, 대학원 28, 외국인 6으로 표시됐습니다(챌린지스퀘어 집계가 아니라 가이드의 표시입니다).

## 정보 구조와 기능 (매뉴얼 기준)
- 상위 메뉴 10개: 비교과프로그램, 학생성공대시보드, 역량진단, 3품인증, 취업/창업활동, 학생활동, 국제교류, 외국인유학생, 상담영역, e-포트폴리오.
- 비교과프로그램: 학생성공 가이드 조회, 비교과 수강신청, 나의 수강신청 내역, 교외이수비교과승인신청, 이수내역조회, 이수증명서발급, 디지털 배지.
- 역량진단(SSCA)은 별도 메뉴입니다. 학교 학생성공역량은 자기주도성, 글로벌, 시민의식, 융합, 기업가정신 5가지입니다.
- 개인화 프로그램 추천과 추천 이유 설명은 찾지 못했습니다.

## 프로그램 목록과 상세
- 목록: 키워드 검색(쉼표로 여러 개), 체크박스 필터 4개(디지털배지여부, 도전학기, 나의 스크랩 보기, 3품인증대상), 정렬 3개(신청 마감순, 최신 등록순, 스크랩순), 카드/테이블 보기.
- 카드 1장에 정보가 12~13개(모집 상태, D-day, 포스터, 스크랩, 운영 부서, 제목, 연락처, 조회·스크랩 수, 역량 칩 5개, 신청·운영 기간, 인정 시간 등) 들어갑니다.
- 상세 팝업: 신청기간, 운영기간, 인정시간, 장소, 3품인증, 캠퍼스, 디지털배지, 신청 인원과 공지내용·기본정보·수업시간/계획서·수강후기 탭. 신청 대상은 공지 본문의 자유 텍스트에 있습니다.
- 로그인 뒤 신청까지 약 3~4번 클릭(비교과프로그램 → 비교과 수강신청 → 카드 + → 신청하기). 상태는 신청완료 → 수강확정 → 수강완료 순으로 바뀝니다.

## 학생이 직접 해야 하는 일
- 대상 조건을 공지 본문에서 찾아 읽기
- 일정 충돌 확인(기능 없음)
- 날짜만 다른 같은 강연 카드 구분
- 수강확정 여부를 다시 들어가 확인
- 활동 뒤 의미 정리(이수 기록·증명서·배지·후기는 있지만 자기이해로 잇는 장치는 없음)

## 차별화에 쓴 관찰
1. 목록이 로그인 뒤에만 있고 정보는 여러 공개 경로에 흩어져 있다 → 에이전트가 모아서 하나로 고른다.
2. 정렬·필터만 있고 개인화 추천과 이유가 없다 → 내 기록에 근거한 이유 1줄.
3. 자격·충돌·중복·수강확정 확인이 학생 몫이다 → 에이전트가 미리 확인하고 챙긴다.
4. 활동 뒤에는 증빙과 평가(후기)가 남는다 → 30초 회고로 기록·발견·다음 추천을 잇는다.
5. 5대 역량 진단이 목록과 떨어져 있다 → 활동 반응을 발견으로 쌓고, 학교 역량 체계와의 매핑은 다음 과제로 둔다.
