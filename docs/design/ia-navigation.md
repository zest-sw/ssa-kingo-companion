# 화면 깊이와 이동 동선 (v0.9)

> 근거: Notion '레이아웃 레퍼런스 조사'(2026-10-30, 사본 docs/product/layout-reference.md), 기준 문서 docs/product/concept.md.
> 사용자 요청(2026-11-02): "처음 화면에 글씨만 많아 난잡하다. 각 메뉴의 첫 화면은 다이어그램 위주로 전체·핵심 정보를 한눈에, 누르면 상세. 화면 깊이와 이동 동선을 설계하고 사용자 친화적으로."

## 1. 원칙

1. **첫 화면은 그림, 상세는 한 번 눌러서.** 각 메뉴의 첫 화면(L1)은 다이어그램 하나가 주인공이다. 글은 라벨과 한 줄 캡션만 쓴다. 문단, 설명 목록, 표는 L2 이하로 내린다.
2. **모든 그림 조각은 길이다.** L1 다이어그램에서 보이는 칸, 막대, 점, 노드는 전부 눌러서 해당 상세(L2 경로 또는 L3 서랍)로 간다. 누를 수 있는 것은 hover/focus 표시가 있고, 키보드로도 된다.
3. **깊이는 3단을 넘지 않는다.** L0 메뉴 → L1 개요 → L2 상세 화면 → L3 서랍(항목 하나). 확인 질문만 모달.
4. **돌아오는 길이 보인다.** L2 머리에는 빵부스러기(메뉴 › 상세)와 뒤로 버튼. 뒤로 가면 L1 의 같은 선택·스크롤로 돌아온다. 브라우저 뒤로 가기도 같은 결과.
5. **대시보드형 숫자판은 쓰지 않는다**(레퍼런스 조사 판단). 숫자는 진행도·개수처럼 나 자신에 대한 사실만, 그림 안 라벨로. 점수·순위·비교 없음.
6. **같은 것은 같은 모양.** 분야 색·상태 모양·날짜 표기는 모든 화면에서 같다. 같은 대상(활동, 기록, 기회)을 누르면 어디서든 같은 서랍이 열린다.

### 측정 가능한 기준
- L1 첫 화면(1440×900, 스크롤 전)의 본문 글자 수(라벨·버튼 제외 문장) 300자 이하. v0.8 홈은 이보다 훨씬 많다.
- L1 에서 핵심 정보(이번에 할 것, 다가오는 마감)를 보는 데 클릭 0, 어떤 상세도 L1 에서 클릭 2번 이내.
- L1 의 다이어그램 요소 중 누를 수 없는 장식 요소 0.

## 2. 지도 (L0 → L1 → L2 → L3)

## 3. 핵심 동선 (과업별 클릭 수 목표)

1. **이번에 뭐 할까 → 신청**: 홈 ① 가장 추천 → (추천 상세 또는 바로) 신청 준비 → 체크리스트 → 이대로 신청 → 내 활동 타임라인에 막대가 생김. 홈에서 신청 준비까지 클릭 1번.
2. **다른 걸 보고 싶다**: 홈 ② 대안 또는 추천 L1 '다른 대안' → #/recommend/list(목록-상세). 클릭 1번.
3. **활동이 끝났다 → 회고**: 홈 ③ 타임라인의 회고 대기 점 또는 기록 L1 맨 위 줄 → 회고 인터뷰 → 저장 → 완료 화면에서 '기록 지도에서 보기'. 클릭 1번으로 인터뷰 시작.
4. **나는 어떤 사람인가**: 홈 ④ 고리의 '분석' 노드 또는 메뉴 → 분석 L1 타일 → 해당 탭. 발견 확인은 L1 개수 표시 → 경험 지도 위 카드.
5. **친구·팀원**: 친구 L1 → (비공개면) 설정의 공개 범위 → 돌아오면 L1 이 열린 상태.

모든 완료 화면·토스트에는 "다음에 갈 곳" 하나만 버튼으로 둔다.

## 4. 공통 부품 (src/components, 기반 워커)

- **PageHeader**: L1 은 제목 + 오른쪽 주 행동 1개만(설명 문단 없음). L2 는 빵부스러기(메뉴 › 상세) + 뒤로 버튼 + 제목.
- **Diagram 기본 부품**(SVG 또는 CSS, 외부 차트 라이브러리 없이): Timeline(가로 날짜 축 + 점·막대·오늘 선), Gantt 행, DotGrid(행·열 격자에 점), Funnel(단계 막대), SegmentBar(분야 비율 막대), MiniTile(작은 그림 + 제목 + 화살표, 전체가 링크), Loop(노드 3개 순환). 모든 조각은 클릭·키보드 가능 요소로 렌더하고 aria-label 에 값이 들어간다. 범례는 그림 옆 한 줄.
- **뒤로 상태 보존**: 메뉴별 L1 선택·스크롤을 기억해 L2 에서 돌아올 때 복원.
- **EntityDrawer**: 기회·활동·기록을 어디서 눌러도 같은 서랍(이미 있으면 공용으로 정리).

## 5. 글 줄이기 규칙

- L1 에서 지울 것: 안내 문단, 원칙 설명("필요한 정보만 보여 줘요" 같은 메타 문장), 같은 말 두 번, 표.
- 남길 것: 라벨(2~6자), 값, 한 줄 캡션(25자 안팎) 최대 1개/조각.
- 메타 문장(우리는 점수를 안 써요 등)은 설정 › 프로토타입 정보로 옮긴다.
