| 나중에 보기 서랍 | `추천 목록으로 돌려놨어요.` | `추천에 다시 넣었어요.` | 결과 과거형 |
| 신청 준비 | `안 할래` / `고쳐 줘` | `그만두기` / `초안 고치기` | 버튼은 행동, 반말 없음 |
| 신청 준비 | `가장 급한 것 · 10월 14일까지 사전 설문` | `10월 14일까지 사전 설문` | 빼도 같은 말 |
| 신청 준비 초안 | `관련 경험 · 기록 보관함에서 가져옴` | `경험 · 내 기록에서 가져왔어요` | 잡초 단어(관련) |

| 어떻게 골랐나 | `단계를 누르면 거기서 빠진 활동을 볼 수 있어요.` | `… 빠진 활동이 나와요.` | '~할 수 있어요' |

| 홈 오늘의 퀘스트 | `외 1개 · 내 활동에서 볼 수 있어요` | `1개 더 있어요` | 빈 문장 |
| 홈 오늘의 퀘스트 | `첫 퀘스트로 이걸 받아 보세요` | `첫 퀘스트로 이 활동을 추천해요` | 퀘스트 = 추천 활동 |
| 홈 오늘의 퀘스트 빈 상태 | `오늘은 받은 퀘스트가 없어요. 광장의 퀘스트 게시판을 둘러보세요.` | `오늘 챙길 일은 없어요. 퀘스트 게시판에서 다음 활동을 골라 보세요.` | 다음 행동 |
| 홈 광장 | `퀘스트 게시판 / 활동 탐색` | `퀘스트 게시판 / 나에게 맞춘 추천 활동` | 게임 말 보조 문구 |
| 홈 광장 | `명예의 전당 / 먼저 걸어온 길 / 걸어온 길 4` | `… / 먼저 간 사람들의 길 / 4명의 이야기` | 같은 말 두 번 |
| 홈 광장 | `시 지 도 최근` | `시 지 도 최근 오른 사람` | 뜻 모를 표시 |
| 홈 상태창 | `아직 없어요`(가장 깊이 간 분야) | `첫 기록 뒤에 생겨요` | 빈 상태는 다음 일 |
| 내 활동 한눈에 | `나머지 8개는 일정에서 볼 수 있어요` | `8개 더 있어요` | 빈 문장 |
| 내 활동 한눈에 | 행마다 `회고 쓰기 ›` ×3 | 행 끝 아이콘만(이름은 `… 회고 쓰기`) | 같은 말 반복 |
| 일정 | `이번 달 활동 7개가 더 있어요 · 학기 전체에서 볼 수 있어요` | `이번 달 활동이 7개 더 있어요` | 빈 문장(옆 버튼이 학기 전체 보기) |
| 일정 보드 | `기록함·안 됨 3개 더 보기` | `정리된 활동 3개 더 보기` | 접기 버튼과 같은 이름 |
| 활동 상태 | `이번엔 안 됐어요. 다음 모집에서 다시 볼 수 있어요` | `… 다음 모집이 열리면 알려 줄게요` | '~할 수 있어요' |
| 기록 | `기록만 남겼어요. 기록에서 언제든 채울 수 있어요.` | `기록만 남겼어요. 회고는 나중에 써도 돼요.` | '~할 수 있어요' |

| 면접 답변 | `쓴 말을 STAR 순서로 이었어요.` | `쓴 말을 상황·역할·한 일·결과 순서로 이었어요.` | 배워야 하는 개념 |
| 기록 서랍 머리 | `2026-2학기 · 창업·기획 · 비교과` | `2026-2학기 · 창업·기획` | 가운뎃점 사슬 |
