# 디자인 비평 2: 여러 라운드가 지난 뒤 처음 보는 눈으로 (v36-critic2, 2026-11-06)

v2.9 비평(`design-critique-2026-11-06.md`) 뒤로 v3.0~v3.5 가 움직임, 크기별 틀(최대 1440), 서랍 주소, 키보드, 화면 나누기 뼈대, 칩·토스트 규칙을 더했다. 여러 워커가 따로 고친 자리에 생긴 어긋남을 `DESIGN.md` 계약에 대 보고, 공용에서 먼저 고쳤다.

## 결론
- 틀은 단단하다. 세 크기(1280×640·1440×900·1920)에서 머리·구역 탭·본문 왼쪽 끝이 모든 화면에서 같은 자리고, 넘침·잘림·페이지 스크롤이 없다(레이아웃 검사 679화면 0건). 실루엣은 화면마다 다르다(간트, 가지 지도, 트리, 점 지도, 육각형). 1차·2차 AI 티는 새로 생기지 않았다.
- 새 어긋남은 **움직임**에 몰렸다. 같은 일(흐름 화면의 단계 넘김, 끝 장면)을 세 흐름이 세 가지 거리·투명도·크기로 움직였고, 신청 완료 표시는 튀었고(넘쳤다 돌아오는 크기), 명예의 전당은 640ms 로 다른 열림의 세 배였다.
- 찾은 것 **P1 4갈래, P2 9갈래**. P1 은 모두 고쳤고, P2 는 7개 고치고 2개는 제안으로 남겼다.

## 본 방법
- `npm run audit:layout`(새 학생 두 상태 + 예시 × 7크기, 679화면) 스크린샷을 크기·상태별 접촉 시트로 모아 봤다.
- 레이아웃 검사가 보지 않는 것은 따로 찍었다(Playwright, 새 학생·예시 × 1280×640·1440×900·1920×1080): 기회 자세히 모달, 어떻게 골랐나 모달, 나중에 보기 서랍, 나중에 보기·관심 없음 토스트, 내 활동 서랍, 경험 카드 서랍, 강점 근거 서랍, 발견 모두 보기 서랍, **느린 망 뼈대**(화면 덩어리를 4초 늦게 받게 하고 홈에서 추천으로). 콘솔 에러 0.
- avoid-ai-design: 스캐너(`audit:design` P0 0 · P1 0 · P2 36, 전과 같음, 모두 이름 속 가운뎃점·테스트 문구) + 실루엣(진한 픽셀만) + 흐림 검사.
- 움직임: 화면 CSS 의 `animation`·`transition`·`@keyframes` 를 다 훑고, 같은 일을 하는 것끼리 값을 대 봤다. 고친 뒤 브라우저에서 계산된 animation 이름·길이를 확인했다.
- kingo-toss-ux 점검표, kingo-ux-writing(토스트 문구 전부 훑기).

### 고치지 않고 본 것
- 느린 망 뼈대: 머리·탭·본문 자리가 실제 화면과 같고 300ms 전에는 안 보인다. 다만 본문 칸이 모든 화면에서 2:1 카드 두 장이라, 추천(띠 + 목록)·흐름 화면은 덩어리가 오면 모양이 바뀐다(제안 2).
- 이번 주 그림의 오늘 선은 축소 이미지에서 회색처럼 보였는데 픽셀 값은 `--accent`(212,104,44)였다. 문제 없음.
- 칩: 켜짐(초록 테두리 + 600)·꺼짐·hover·눌림이 공용 하나로 맞다. 화면에서 칩을 따로 그리는 곳 없음.
- 1920: 모든 화면이 1440 틀 안 같은 x. 늘어난 빈 카드 없음.
- 서랍 주소(`?drawer=`)로 연 서랍과 눌러서 연 서랍이 같은 모양.

## 2. 토스 기준 마지막 질문 (화면마다 한 줄)

| 화면 | 한 가지 메시지 | 다음 행동 보이나 | 빼도 되는 것 |

## 5. 남긴 제안 (배치·공용 틀이라 다음 라운드)
1. **모달 위 토스트**(P2-9): 낮은 화면에서 넓은 모달이 열려 있을 때 토스트가 행동 줄을 덮는다. 토스트 한 자리 결정(v3.1)을 지키려면 넓은 모달이 열려 있을 때만 모달 아래 여백을 토스트 높이만큼 두거나(`.ui-scrim--center` 의 아래 padding), 모달 안 토스트는 모달 행동 줄 위로 붙인다. 결정이 필요하다.
2. **뼈대 모양**(`src/app/ScreenFallback.tsx`, 공용 틀): 본문이 모든 화면에서 2:1 카드 두 장이다. 추천은 띠 한 줄 + 목록, 흐름 화면은 가운데 한 칸이라 덩어리가 오면 모양이 바뀐다. 화면별 뼈대 모양(띠/목록/두 열) 세 가지를 경로 표에 달고, 제목 막대 대신 이미 아는 페이지 제목 글자를 바로 그리면 기다리는 동안에도 어디인지 안다(토스 09 '뼈대는 실제 모양 그대로'). 로딩 막대(반짝임)와 뼈대 막대(가만히)는 높이·색을 맞췄고, 반짝임을 뼈대에도 줄지는 이때 함께 정한다.
3. **프로필·친구 경험 카드 이름**(`.fr-path`): 누르지 않는 이름이 1px 상자 칩 모양이라 버튼처럼 읽힌다. DESIGN '분야 = FieldTag(점 + 이름)'으로 상자를 빼는 쪽.
4. v2.9 비평에서 남긴 것 중 아직 남은 것: 기회 자세히 머리 배지 줄(P1-7)·사실 칸 타일(P2-9), 범례 자리(P2-6), 카드 안 카드(P2-8), 근거 서랍 점 줄(P2-12).
5. 신청 준비 초안의 '바뀐 문장 짚기'(`rec-changed`, `--dur-base` × 8)는 읽을 시간이 필요해 Flash(`--dur-flash`)보다 길게 둔 것으로 보고 두었다. 같은 '바뀐 것 한 번 강조'라 토큰 하나(`--dur-linger`)로 이름을 붙일지 정하면 된다.
