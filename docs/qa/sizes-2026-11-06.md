# 크기별 배치 (v33-wide, 2026-11-06)

세 크기(1280×640 · 1440×900 · 1920×1080) × 두 학생 상태(새 학생 · 예시)로 모든 화면을 찍어 나란히 보고, 크기마다 규칙을 정했다(DESIGN.md Layout '크기별'). `npm run audit:layout` 은 넘침·잘림만 보므로 '보기 좋은가'는 눈으로 봤다.

## 스크린샷 위치

worktree 의 `.qa/sizes-2026-11-06/`(저장소에는 안 들어간다, `.qa/` 는 무시 목록).

- 한 장씩: `.qa/sizes-2026-11-06/{before,after}/{new,example}/{1280x640,1440x900,1920x1080}/<경로>.png`
- 대조표(2상태 × 3크기 한 장): `.qa/sizes-2026-11-06/sheets/{before,after}/<경로>.png`
- 1280×640·1440×900 은 `npm run audit:layout` 결과, 1920×1080 은 같은 검사를 1920×1080 한 크기로만 돌린 사본(검사 크기 표에는 1920×960 이 있다)으로 찍었다.

## 크기마다 규칙(요약)

| | 1280×640 | 1440×900 | 1920×1080 |
|---|---|---|---|
| 본문 폭 | 칸 전체 | 칸 전체 | 모든 화면 최대 1440px 가운데(머리·탭 x 가 화면마다 같음) |
| 남는 높이 | 간격 → 보조 줄 → 나란히 순으로 줄임 | 기본 | 카드는 내용 높이, 남는 곳은 바탕. `.only-tall` 로 다음 걸음 한 단계 |
| 흐름 화면 | 위 | 위 | 창 높이에 비례해 내림(최대 192px, 단계와 무관) |

## 안 바꾼 것과 이유

- 홈·프로필은 1920×1080 에서 아래에 바탕이 남는다. 카드를 늘리거나 덩어리를 늘리지 않았다(첫 화면 덩어리 3개 상한).
- 처음에는 카드 화면만 1280px 로 묶어 1920 에서 화면을 오가면 제목이 약 170px 옆으로 옮겨 갔다. 지휘자 판단(머리·탭은 늘 같은 자리)으로 모든 화면을 1440px 하나로 묶었다. 1920×1080 에서 홈→추천→내 활동→일정→나의 분석→경험 지도→프로필을 눌러 잰 제목·구역 탭·본문 왼쪽 x 는 모두 350.
