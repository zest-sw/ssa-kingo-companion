# 설정·가입 인터뷰 점검 (2026-11-04, v2.1)

기준: `docs/product/concept.md` '추천에 쓰는 데이터(안)' 표, 공개 동의 문단, 레퍼런스(Steam 공개 범위). 화면은 `#/settings/*` 5칸과 새 학생 첫 홈(가입 인터뷰).

| 항목 | 고치기 전 | 고친 뒤 | 무엇을 했나 |
| --- | --- | --- | --- |
| 데이터마다 어디서 왔고 무엇에 쓰는지 한 줄 | 약함(학교 데이터만 한 줄) | 있음 | 내가 알려 준 것 5줄 모두 출처·쓰임 한 줄 |
| 학교 데이터는 동의 단계를 거치나 | 없음(배지만) | 있음 | GLS·i-Campus·챌린지스퀘어 각각 '동의 안내'(읽는 것·쓰는 곳·끊기). 실제 연결은 없다고 밝힘 |
| 내보내기·지우기 길 | 없음(지우기는 프로토타입 정보에만) | 있음 | 데이터 칸에 '내려받기'(JSON, 분석 결과 제외), '지우기'(확인 창) |
| 공개 범위: 항목별·기본 비공개 | 있음 | 있음 | 그대로 |
| 비공개일 때 '보일 것 고르기' 안내 | 어긋남('켜진 것만 친구에게 보여요'인데 비공개) | 있음 | 비공개면 '지금은 안 보여요, 미리 골라 두면 공개할 때 이것만' |
| 고르기 안 제목 중복(분절 + 묶음 제목) | 약함 | 있음 | 묶음 제목 뺌 |
| 분석은 항상 나만 | 있음 | 있음 | 데이터 칸 안 한 줄로 합침(묶음 4→3) |
| 알림 하루 한 번 묶음 | 있음 | 있음 | 그대로 |
| 가입 인터뷰 3단계·바로 첫 추천 | 있음 | 있음 | 그대로 |
| '아직 모르겠어요'가 자연스러운가 | 약함(고른 뒤 반응 없음) | 있음 | 고르면 '안 해 본 분야부터 보여 드릴게요' |
| 가입 중 데이터 사용 안내 | 없음 | 있음 | 3단계에 '학교 데이터는 동의한 것만 써요' 한 줄 |

남은 것: 학교 데이터 연결 상태(동의함/끊음)를 저장하는 곳은 없다(`Settings` 공용 타입 변경이 필요해 보고만). 알림 시각은 하루 한 번만 고른다.
