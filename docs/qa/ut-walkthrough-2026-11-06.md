# 처음 쓰는 학생처럼: 과제 기반 사용성 걷기 (v32-ut, 2026-11-06)

## 결론
- 7개 과제를 새 학생(가입 인터뷰 직후, 멘토링)과 예시 학생(3학년, 기록 25개) × 1440×900·1280×640 으로 모두 끝까지 걸었다. 콘솔 에러 0, 페이지 스크롤 0.
- **P1 하나**: 관심 없음은 7초짜리 토스트에서만 되돌릴 수 있었다. 토스트를 놓치면 길이 없었다(전체 기회에서 열어도 '관심 없음' 버튼만 그대로). 고쳤다.
- **P2 넷을 고쳤다**: 프로필은 '경험 카드', 공개 범위는 '회고'라고 같은 것을 다르게 부름 / 1280×640에서 '처음부터 다시'가 칸 아래로 밀림 / 새 학생 홈의 '이번 주 마감은 없어요'가 옆 카드의 'D-3 마감'과 부딪힘 / 새 학생이 지난 활동을 기록할 길을 홈에서 알 수 없음.
- 지휘자가 본 것: 명예의 전당 장면을 본문 가운데에서 머리 바로 아래로 올렸다(장면 높이는 내용 높이 그대로).
- 클릭 수는 거의 그대로다. 고친 것은 막다른 길과 헷갈리는 말이라서 망설임 횟수가 줄었다(아래 전/후 표).

## 방법
- 걷는 스크립트: `.qa/ut/ut.mjs`(Playwright, dev 서버 5913). 학생이 누른 것만 센다(글자 입력·체크는 따로 적고 세지 않음). 과제마다 새 브라우저에서 학생 상태를 처음부터 만든다.
- 스크린샷: `.qa/ut/<before|after>/<과제>-<new|example>-<크기>/NN-<단계>.png` (로컬 산출물, 커밋하지 않음). 결과 표: `.qa/ut/<before|after>/result*.json`.
- 망설임은 스크린샷을 처음 보는 눈으로 읽고 적었다: 어디를 눌러야 할지 몰랐던 순간, 읽고도 뜻을 몰랐던 말, 기대와 다른 결과.
- 분류: Nielsen 휴리스틱 번호(H1 상태 보이기, H2 실제 세계의 말, H3 사용자 통제·되돌리기, H4 일관성, H5 오류 예방, H6 기억보다 알아보기, H7 유연성, H8 미니멀, H9 오류 회복, H10 도움말)와 kingo-toss-ux 원칙 번호(01~10). 심각도 P1 막힘 / P2 헤맴 / P3 다듬기.
