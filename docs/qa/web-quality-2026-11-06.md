# 웹 품질 점검 (v29-quality, 2026-11-06)

기준: `.claude/skills/web-interface-guidelines`(키보드·초점·폼·움직임·주소 상태), `kingo-toss-ux` 5절 점검표, `kingo-ux-writing`(빈 상태 문구). 범위: `src` 전체. 접근성·상태만 최소로 고치고, 배치와 문구는 다시 짜지 않았다.

## 1. 방법

- 영역 넷(공용 부품·앱 틀 / 홈·추천 / 내 활동·기록 / 분석·프로필·설정)을 코드로 읽어 `file:line` 목록을 만들었다.
- 키보드 걷기: 22개 경로 × 두 학생 상태 × 1280×640·1440×900 에서 Tab 을 끝까지 눌러 초점 자리마다 링·이름·32px·가림을 쟀다.
- 흐름 걷기: 두 학생 상태 × 두 크기에서 홈 → 신청 준비(준비할 것 → 초안 → 신청 → 뒤로 가기) → 추천(어떻게 골랐나) → 내 활동(일정 → 보드 → 기록 → 회고) → 나의 분석(테크 트리) → 프로필 → 설정(공개 범위)을 **마우스로 한 번, Tab·Enter·Esc 만으로 한 번** 통과했다. 단계마다 스크린샷을 찍어 봤다.

## 6. 자기 비평

- 초점 이동을 화면마다 따로 넣었다(제목, 묶음, 버튼). 공용 규칙("누른 버튼이 사라지면 가까운 제목으로")을 한 곳에 두면 더 단단하다.
- 단계 주소는 이어 하기 저장값과 주소가 둘 다 단계를 안다. 처음 그릴 때는 저장값이 이기도록 했지만, 두 근원을 하나로 줄이지는 못했다.
- 키보드로 사이드바에 가려면 그림이 많은 화면(테크 트리 → 프로필 42번)에서 Tab 이 길다. 본문으로 건너뛰기는 있지만 '메뉴로 건너뛰기'는 없다.

## 7. 남은 것 (스코프 밖·다음에)

- 기회·활동·기록 서랍(`src/app/entity.tsx`)은 주소에 안 남아 뒤로 가기로 닫히지 않는다(`ponytail` 표시된 알려진 한계). 분석 화면의 서랍(테크 트리 노드, 경험 지도 이어짐, 관심 흐름 학기, 강점)도 같다.
- 경험 지도는 조각마다 Tab 이 서서 50번 넘게 눌러야 지나간다. 한 번만 서고 방향키로 옮기는 방식(roving tabindex)이 맞다. 노드 끌어 고정하기는 키보드 대안이 없다('처음 배치로'는 있음).
- 가입 인터뷰 단계는 주소에 없다(첫 실행 화면이라 앞 기록이 없고 '이전' 버튼이 있다).
- 토스트 '되돌리기'는 5초 뒤 닫혀 키보드로 닿기 빠듯하다. 토스트는 v29-polish 가 손보는 파일이라 시간은 바꾸지 않았다.
- 경험 카드 묶음에서 고른 기록을 지워 1장이 남으면 처음과 같은 빈 문구가 나온다("1장 더 고르면 묶음이 돼요"로 나누기).
- 친구 요청 '다음에'는 되돌리기가 없다. 설정 추천 조건은 저장 안 한 채 다른 칸으로 가면 말없이 사라진다.
- 입력 칸 예시 문구 끝 `…`(가이드라인)는 우리 문구 기준(copy-pass)에 없어 따르지 않았다.
