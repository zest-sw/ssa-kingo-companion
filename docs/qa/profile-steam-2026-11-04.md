# 프로필 · 스팀 레퍼런스 점검 (2026-11-04, v2.0)

기준: `docs/product/concept.md` '레퍼런스에서 가져올 기능' › '도전 과제와 친구 (현재)'. 화면은 `#/profile` 과 하위(친구·팀원 모집·명예의 전당), 전체 목록 서랍.

| 스팀 → 우리 서비스 | 고치기 전 | 고친 뒤 | 무엇을 했나 |
| --- | --- | --- | --- |
| 업적(이름·설명·아이콘·달성 시각) → 도전 과제 | 있음 | 있음 | 전시 칸과 고르기 서랍에도 달성 날짜 |
| 숨김 업적 → 숨은 과제 'N개 남음' + 일부 힌트 | 약함(프로필엔 '숨은 과제 N'만) | 있음 | 'N개 남음' + 힌트 한 줄. 힌트는 숨은 과제 넷 중 둘만 |
| 진행도 막대 | 있음 | 있음 | 그대로 |
| 전체 달성률 % → 희귀도 단계 | 약함(전체 목록에만, 희귀가 주황 면) | 있음 | 프로필 다음 과제에도. 단계 이름 + 네이비 마름모 1~3개, 퍼센트 없음 |
| 프로필 쇼케이스 → 학생이 고름 | 약함(전체 목록 카드마다 스위치, 개수 제한 없음) | 있음 | 머리의 '전시 고르기' → 서랍에서 1~3개, 누른 순서대로. 진입점 하나(카드 스위치는 뺌) |
| 배지·레벨·XP → 학기·행사 배지 | 없음 | 없음 | 이번 범위 밖. 레벨·XP는 계속 없음 |
| 친구 신청·소식 → 서로 수락, 소식과 응원 | 약함(응원 수 숫자) | 있음 | 응원은 눌렀는지만('응원함'), 수는 세지 않음 |
| 이 게임을 하는 친구 → 이 활동을 해 본 친구·선배 | 약함(이름 글자만) | 있음 | 이름을 누르면 친구는 친구 프로필, 선배는 경로 서랍 |
| 큐레이터 → 선배 활동 경로 따라 보기 | 약함(명예의 전당 시간 목록만) | 있음 | 테크 트리처럼 짧은 경로(줄=시간, 칸=입문·중급·심화). 공개하지 않은 선배는 이름만 점선 |
| 공개 범위 → 항목별, 기본 비공개 | 있음 | 있음 | 비공개면 하위 화면은 '공개하면 열려요' 한 화면 그대로 |
| Steam Replay → 학기 돌아보기 | 없음 | 있음 | '나' 덩어리 안: 지난 학기 vs 이번 학기 기록·처음 해 본 분야·해 본 역할. 다른 학생 값 없음 |

남은 것: 학기·행사 배지, 예시 학생의 달성 시각(`EXAMPLE_CHALLENGE_AT`, `src/app/state.ts`)이 오늘보다 뒤인 날짜(11월 27일)가 있음, 방학 기록은 학기 돌아보기에 안 들어감(`// ponytail`).
