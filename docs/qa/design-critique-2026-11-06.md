# 디자인 비평: 한 제품처럼 보이나, AI 티가 남았나 (v29-critic, 2026-11-06)

처음 보는 디자이너의 눈으로 v2.6~v2.8 배포본 전체를 한 번에 봤다. 화면마다 따로 고치며 생긴 어긋남(디자인 시스템 표류, avoid-ai-design X1)과 남은 AI 티를 찾고, 역할마다 모양 하나를 정해 `DESIGN.md` 에 계약으로 남겼다.

## 결론
- AI 티는 1차·2차 모두 거의 없다. 보라 그라데이션·Inter·세 장 카드·크림+테라코타·검정+형광·대문자 눈썹·01/02/03 없음. 실루엣 검사에서 화면마다 덩어리가 다르다(간트, 지도, 테크 트리, 육각형). 남은 것은 **같은 역할인데 모양이 다른 곳**이다.
- 찾은 것: **P1 7갈래, P2 12갈래.** 공용 부품·토큰·공용 CSS 에서 먼저 고쳤고, 배치를 바꿔야 하는 것은 남겼다(아래 '남긴 것').
- 스캐너 P1 9건은 모두 주석·검사 코드 속 기호이거나 일부러 고른 개수 표기였다. 주석 문구를 고치거나 이유와 함께 무시 표시를 달아 0건이 됐다.

## 본 방법
- 스크린샷: `npm run audit:layout` 이 찍은 `.qa/layout/{new,example}/1440x900/*.png` 59장 + 모달·서랍·토스트 5장(Playwright, 예시 학생: 어떻게 골랐나, 기회 자세히, 관심 없음 토스트, 내 활동 서랍, 강점 근거 서랍). 콘솔 에러 0.
- 스캐너: `npm run audit:design` (avoid-ai-design detect v0.4.0). 고치기 전 P0 0 · P1 9 · P2 36.
- 실루엣 검사: 스크린샷을 진한 픽셀만 검게 남겨 220px 로 줄였다. 25% 흐림 검사: 360px 로 줄이고 흐렸다(밀도·리듬).
- 화면마다 kingo-toss-ux 5절 점검표 한 줄.

### 실루엣 · 흐림 검사
- 실루엣: 홈(띠 + 육각형 + 두 열), 추천(주인공 띠 + 표 같은 목록), 내 활동(주간 간트), 기록(가지 지도), 분석(지도·트리·육각형)이 서로 다르다. 설정 다섯 장만 흔한 설정 화면 모양인데, 설정은 그게 맞다.
