## 결과

- 고친 항목 7개(1·3·4·5·8·10·11), 나머지 6개는 이미 있거나 지킨 항목. 커밋: 003e839(새 학생 근거), 3c0e166(고르기·자세히), ece5f8c(신청 준비), 0d9d998(새 학생 근거 서랍 문장).
- 검사: npm run check(575), build, audit:entries(46), audit:layout 전체 616/616 통과(경고 0).
- 클릭 흐름(예시·새 학생 멘토링·새 학생 창업·기획+목표 세 상태, 1280×640): 추천 → 대안 고르기 → 자세히 → 근거 서랍 → 기록 근거 끄기·다시 켜기 → 신청 준비 → 초안 체크 → 초안 확인 → 신청 단계 → 고쳐 줘 → 칩으로 고치기 → 이대로 신청 → 일정 등록 확인 → 일정에서 보기. 콘솔 에러 0.
- 못 한 것
  - 홈 가장 추천 카드(src/screens/home/HomePick.tsx)는 스코프 밖이라 새 학생 근거 규칙을 넘기지 않았다. traceNodes 에 newcomer 인자만 더하면 같은 설명이 나온다.
  - 목표 → 분야는 낱말 어림(ponytail). 목표가 추천 순위에는 쓰이지 않아 '목표' 점은 같은 분야일 때 설명으로만 붙는다.
  - '남은 마감 챙기기'는 신청 준비 화면의 '가장 급한 것' 한 줄이다. 실제 알림 발송은 없다.
