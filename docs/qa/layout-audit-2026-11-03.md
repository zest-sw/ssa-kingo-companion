`npm run audit:layout` 첫 실행 결과. 화면 616개(학생 상태 4 × 크기 7 × 경로·단계), **실패 191건 · 경고 29건**. 같은 오류가 여러 크기·상태에서 나온 것은 한 줄로 묶었다. 낱낱의 표는 `.qa/layout/report.md` 에 생긴다.
이 단계에서는 고치지 않았다. 고친 뒤 `npm run audit:layout` 이 통과하면 이 문서의 실패 줄이 모두 닫힌 것이다.

- 상태: **새** = 가입 인터뷰에서 '멘토링' 하나 + 기본값, **모름** = '아직 모르겠어요' + 기본값, **예시** = 예시로 둘러보기, **가입** = 가입 인터뷰 단계 1~3.
- 크기 줄임: `640`=1280×640, `650`=1366×650, `700`=1440×700, `730`=1536×730, `900`=1440×900, `960`=1920×960, `1024`=1024×640(깨지지 않음만 봄). '전 크기'는 1024 를 뺀 6개.
- 찾은 곳: **기계**(검사가 잡음), **눈**(지휘자가 눈으로 찾았고 기계는 못 잡음), **기계+눈**(둘 다).
- 판단: **오류**는 고친다. **표시**는 채우는 게 의도인 칸이라 화면에 `data-fill` 만 붙이면 된다(의도가 아니면 내용 높이로).
- 스크린샷은 `npm run audit:layout` 을 돌리면 같은 경로에 다시 생긴다(`.qa/` 는 저장소에 넣지 않는다). 걸린 곳은 빨간 틀, 경고는 주황 틀로 표시돼 있다.
