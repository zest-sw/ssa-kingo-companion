# 기록·회고 레퍼런스 점검 (2026-11-04, v20-records)

대상: 내 활동 › 기록(`#/activities/records`), 기록 서랍, 회고 대기 진입부, 회고 인터뷰.
기준: `docs/product/concept.md` '회고와 기록 (과거)', '레퍼런스에서 가져올 기능'. 지향점은 '쌓인 활동이 포트폴리오가 된다', '활동이 자기이해로 이어진다'.

## 고치기 전

| 레퍼런스 | 기준 문서가 말한 것 | 고치기 전 | 판정 |
| --- | --- | --- | --- |
| Day One · 회고 바로 열기 | 알림(회고 대기 항목)을 누르면 그 활동의 회고가 바로 열린다 | 홈 '오늘 할 일'의 회고 항목, 활동 서랍·보드 카드, 회고 대기 목록은 바로 열림. 내 활동 '회고 대기' 칸과 기록 화면 띠는 대기가 2개 이상이면 목록(`records/interview`)을 한 번 거침. 칸에는 첫 활동 이름만 보여서 그걸 누르면 바로 열릴 것처럼 보임 | 약함 |
| STAR · 면접용 경험 카드 | 앞 네 항목(상황·역할·한 일·결과)이 STAR 와 같아 면접용 경험 카드로 바로 쓴다 | 서랍에 여섯 칸이 한 줄로 늘어설 뿐 STAR 묶음이 안 보임. 면접 답변으로 바꿔 보거나 복사하는 길 없음. 예시 기록은 카드에 역할만 있어 한 일·배운 점(메모·한마디에 있음)이 서랍에서 비어 보임 | 약함 |
| Gibbs · 배운 점·다음에 해 볼 것 | 뒤 두 항목은 결론과 실행 계획 | 칸은 있으나 STAR 칸과 구분 없이 이어짐 | 약함 |
| 고려대 AI선배 · 추천에 쓰지 않기 | '이 기록은 추천에 쓰지 않기' 스위치는 기록 카드에 | 서랍 맨 아래 '추천에 쓰기' 스위치는 있음. 끄면 무엇이 달라지는지 안내 없음. 화면 전용 스위치를 따로 만들어 씀(공용 Switch 있음) | 약함 |
| Open Badges · 학교 확인 표시 | 학교가 확인한 기록은 학교 확인 표시, 직접 입력은 따로 | 서랍 머리에 '학교 확인/직접 입력' 뱃지, 보관함 줄에 아이콘. 내보내기·묶음에는 없음 | 있음(묶음엔 없음) |
| 기록 보관함 | 학기와 분야로 모아 보고, 학교 확인·직접 입력을 나눔 | 학기 묶음 + 분야·확인 방식 칩 두 줄. 학기·역량으로는 못 거름. 한 줄에 제목·메타만 있어 25개면 긴 세로 목록 | 약함 |
| 포트폴리오(면접 준비) | 기록 카드를 경험 카드로 바꿔 서류·면접에 다시 쓴다 | 없음 | 없음 |

## 고친 것

| 레퍼런스 | 고친 뒤 | 판정 |
| --- | --- | --- |
| Day One | 내 활동 '회고 대기' 칸과 기록 화면 띠가 대기 활동을 이름마다 버튼으로 보여 주고, 누르면 그 활동의 회고 인터뷰가 바로 열림(3개까지, 넘치면 '외 n개'만 목록으로) | 있음 |
| STAR | 서랍을 '경험 카드'로: 경험(상황·역할(과제)·한 일(행동)·결과) / 돌아보기(배운 점·다음에 해 볼 것). '면접 답변' 보기 한 번 누르면 STAR 순서 문단, '복사'. 문단은 학생이 쓴 글만 잇고(이음말은 '그 결과' 하나) 대리 제출 없음. 카드 빈 칸은 메모·한마디로 채우는 규칙(`cardOf`) | 있음 |
| Gibbs | 돌아보기 묶음으로 따로 | 있음 |
| AI선배 | 서랍 아래 '이 기록을 추천에 쓰기' 스위치(공용 Switch) + "끄면 추천과 발견에서 빠져요." 한 줄 | 있음 |
| Open Badges | 서랍 증빙 문장, 묶음 카드마다 학교 확인 표시, 복사 글에도 '(학교 확인)' | 있음(실제 서명 내보내기는 미래) |
| 보관함 | 학기·분야·역량 고르기 + '학교 확인만' 칩을 한 줄에. 학기 안은 카드 격자(분야·날짜, 제목, 미리보기 한 줄, 확인 표시) | 있음 |
| 포트폴리오 | 보관함에서 2~5개 고르기 → `#/activities/records/portfolio` 한 화면에 경험 카드 묶음, '전체 복사'·'인쇄' | 있음(작게) |

## 남긴 것

- 추천에 쓰지 않기를 끄면 빠지는 곳은 추천 후보와 발견(내 패턴)이다. 나의 분석의 강점·테크 트리·경험 지도는 지금도 모든 기록을 센다. 분석 화면은 이 작업 스코프 밖이라 안내문을 '추천과 발견'으로 맞췄다. 분석에서도 뺄지는 지휘자가 정한다.
- 고른 묶음은 이 탭 세션에만 남는다(sessionStorage). 새로 고침은 되고 다른 기기는 안 된다.
- Open Badges 서명 내보내기, 예상 질문 만들기는 기준 문서 '미래'라 넣지 않았다.
