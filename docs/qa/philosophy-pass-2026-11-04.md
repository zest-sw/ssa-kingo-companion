## 6. 결과

- 고친 항목 11개(1·3·5·7·15·21·29·33·35·36·37), 그대로 둔 것은 이미 있거나 지킨 항목.
- 못 고친 것
  - 16 스누즈 '그 사이 모집글이 바뀌면 다시 띄움': 예시 데이터에 모집글 변경 이력이 없다. ETL 연동 때.
  - 20 Things '오늘 저녁' 칸: 항목 3개 상한에서 칸을 나누면 빈 칸이 늘어 시각 표시로 대신했다.
  - 5 활동 서랍 실행 기록의 예시 데이터: src/data/seed.ts 가 스코프 밖이라 준비 중 예시 활동에 체크리스트를 넣지 못했다. 신청 준비를 직접 시작한 활동에는 보인다.
- 검사: npm run check(515), build, audit:entries(46), audit:layout 전체 통과(경고 0). 클릭 흐름(홈 나중에 보기·관심 없음·대안 → 자세히, 추천 카드 → 자세히·신청 준비 → 초안 → 신청 단계, 활동 서랍 실행 기록, 기록만 남기기) 콘솔 에러 0.

## 7. 지휘자 검토 반영 (2026-11-04)

| 지적 | 처리 |
|---|---|
| 내 활동 '회고 0개'가 예시 학생에게 어색함 | 고침: 회고 = 이번 학기 기록 중 회고를 거친 것. 칸 없이 메모·한마디로 된 예시 기록은 회고한 것으로 보고, 사실만 남긴 기록은 뺀다(domain 규칙, seed 는 안 건드림). 예시 학생은 '이번 학기 활동 8개 · 회고 4개' |
| 내 활동 요약 아래가 빔 | 고침: 위 줄 할 일 상태 · 회고 대기, 아래 줄 '10월 일정'(일정 타임라인의 이번 달을 4줄까지). 덩어리 3개 유지, '이번 주 마감' 칸과 '일정 보기' 버튼은 없애고 일정 진입은 카드 제목 링크 하나 |
| '나중에 보기'가 날짜 스누즈인지 | 원래도 날짜 스누즈(내일/3일 뒤/다음 주)였지만 마감 뒤로 미룰 수 있었다. 고침: 내일 / 다음 주 / 마감 3일 전 칩, 마감 전날까지 다시 보이는 날만(같은 날은 하나). 마감이 내일이면 '미룰 수 없어요' 한 줄 |
