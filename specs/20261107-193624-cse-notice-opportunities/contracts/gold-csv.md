# 정답셋 CSV 계약 (`etl/gold/*.csv`, 로컬 전용)

**Feature**: [../spec.md](../spec.md) (FR-029~FR-032) · **Data model**: [../data-model.md](../data-model.md) GoldRow

## 파일

- 초안은 `eval.ts new`가 UTF-8(BOM 포함), 줄 끝 CRLF로 쓰고 모든 칸을 따옴표로 감싼다. 엑셀과 Numbers에서 한글이 깨지지 않게 열린다.
- 읽을 때 받는 인코딩은 UTF-8(BOM 있든 없든)과 EUC-KR(CP949)이다. 엑셀에서 'CSV UTF-8'이 아닌 그냥 'CSV'로 저장해도 읽힌다.
- 따옴표, 쉼표, 줄바꿈이 든 칸은 RFC 4180대로 읽는다. 줄 끝은 CRLF와 LF를 모두 받는다.
- 첫 줄은 머리글이다. 이름이 정확히 같아야 하고, 순서는 상관없다.

## 칸

| 머리글 | 초안 | 받는 값 | 비고 |
|---|---|---|---|
| 링크 | 채움 | `https://cse.skku.edu/cse/notice.do?mode=view&articleNo=<글번호>` | 글 번호로 `cse:<글번호>`를 만든다. 같은 글이 두 줄이면 오류 |
| 게시판 | 채움 | 문자열 | 고치지 않는다(판정에 씀) |
| 제목 | 채움 | 문자열 | 고치지 않는다. 비교는 이 제목·게시판·게시일과 보관한 본문으로 판정한다(다시 돌려도 같은 결과) |
| 게시일 | 채움 | `YYYY-MM-DD` | 고치지 않는다. 마감 연도를 정할 때 쓴다 |
| 기회 | 비움 | `O`, `X`(소문자 가능) | 필수 |
| 종류 | 비움 | 채용, 특강, 해커톤, 대회·공모전, 교육·캠프, 동아리·학회, 봉사, 멘토링, 글로벌, 장학, 교과 | 기회가 O면 필수, X면 비워야 함 |
| 마감 | 비움 | 날짜(`YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD`, `YYYY. M. D.`), `없음`, `그림·첨부` | 기회가 O면 필수, X면 비워야 함 |
| 주최 | 비움 | 문자열, `없음`(빈칸도 없음으로 봄) | 비교할 때 앞뒤 공백과 겹친 공백을 정리한다 |
| 확신 | 비움 | 자유(초안은 `높음`·`낮음`) | 초안은 `낮음`이 위로 오게 정렬. 비교에는 쓰지 않는다 |
| 메모 | 비움 | 자유 | 본문 문장을 옮겨 적지 않는다(이름·연락처가 있을 수 있음) |

- `없음`은 상시 모집·채용 시 마감처럼 정해진 마감이 없다는 뜻이다. `그림·첨부`는 마감이 포스터나 첨부에만 있어 제목·본문 글자로는 알 수 없다는 뜻이다. 둘 다 마감 채움 비율의 분모에서 빠진다. 규칙이 이런 글에 마감을 채우면 마감 정확에서 틀린 것으로 센다.

## 오류 예

```text
정답셋을 읽지 못했어요 (3건):
  12행 종류: 대회 (모르는 종류예요. 쓸 수 있는 값: 채용, 특강, …, 교과)
  40행 마감: 11월 15일 (날짜는 2026-11-15처럼 써 주세요)
  77행 종류: 특강 (기회가 X면 종류를 비워 주세요)
```

## 초안 예

```csv
"링크","게시판","제목","게시일","기회","종류","마감","주최","확신","메모"
"https://cse.skku.edu/cse/notice.do?mode=view&articleNo=228201","채용/모집","[동진쎄미켐] 2026년 11월 신입/경력 정기채용 (~11/15(일))","2026-11-06","","","","","",""
```

