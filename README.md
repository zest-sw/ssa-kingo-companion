# 킹고 컴패니언 · 비주얼 MVP v0.3

성균관대 색상 테마의 React UI 프로토타입. 실제 AI, 학교 계정, 크롤링·ETL은 미연결입니다.

## 실행
Node.js 22.12 이상 권장.

```sh
npm install
npm run dev
```

`npm run check`, `npm run build`로 검사합니다.

## 화면
- 성장 지도: 6축 역량 레이더·강점 분야·추천 카드
- 활동 탐색: 출처·관심사 필터와 상세·저장
- 진로 상담: 3단계 관심사 선택과 데모 대화
- 활동 아카이브: 도형 썸네일, 카드·타임라인, 경험 카드 편집
- 데이터 흐름: 학과/학교/챌린지스퀘어/대외활동 → 수집·ETL → 개인화 추천 설계
- 관심사 설정: 시각 카드 선택

모든 모집 정보와 역량 값은 가상 예시입니다. 입력은 현재 React 메모리 상태에만 유지되며 새로고침 시 초기화됩니다. 실제 추천에서는 지원 조건·마감·원문 URL·수집 및 확인일을 검증해야 합니다.
