# 킹고 컴패니언 · 에이전트 큐레이션 UX v0.7

챌린지스퀘어 위에서 동작하는 에이전트 레이어를 시연하는 React/TypeScript 프로토타입입니다. 매주 비교과 1개를 골라 주고, 활동 뒤 30초 회고를 기록·발견·다음 추천으로 잇습니다. 예시 데이터와 화면 안의 규칙만 사용하며 실제 AI·학교 API·챌린지스퀘어·저장소와 연결하지 않았습니다.

## 실행

```sh
npm ci
npm run dev      # 개발 서버
npm run check    # 타입 검사
npm run build    # 배포 빌드 (dist/)
```

`public/mobile-frame.html`은 빌드 결과를 390×844 iframe으로 열어 모바일 배치를 확인하는 보조 페이지입니다.

## 핵심 흐름 (받기 → 하기 → 남기기 → 알게 되기)

- 온보딩: 관심(최대 3개·모르겠음) → 한 주 시간 → 방식, 3단계. '예시 학생으로 바로 보기' 제공.
- 이번 주: 추천 1개(이유 1줄 + 언제·얼마나·마감), '이걸로 할게요' 1탭. 다른 선택지 2개·쉬기·별로예요·왜 이 활동인가요·고른 방법은 시트로 접어 둠.
- 예정: 남은 일 '챌린지스퀘어에서 신청하기' 하나. 가상 활동이라 실제 신청 링크 대신 안내를 띄움. '활동 다음 날로 이동'은 데모용 시간 이동.
- 30초 기록: 가장 많이 한 일(칩) → 에너지(3단계) → 한마디(선택). 완료 화면에서 기록·발견·진로·다음 4줄로 정리.
- 기록: 자동으로 쌓이는 카드, 직접 추가, 고치기·지우기(발견·공고 연결에 전파, 되돌리기 가능).
- 나: 발견(가설) 맞아요·아니에요·근거, 가까워지는 방향(카카오뱅크 공개 공고 3건 요건, 2026.10.08 확인), 6축 분포·데이터·개인정보·설계 메모.
