# 킹고 컴패니언 · 연결 성장 UX v0.5

6개 가상 경험을 연결한 React/TypeScript 인터랙티브 프로토타입입니다. 실제 학생 데이터나 AI/API를 사용하지 않습니다.

## 실행

Node.js와 npm이 설치된 환경에서:

```sh
npm ci
npm run dev
npm run check
npm run build
```

TypeScript 검사와 Vite 배포 빌드를 통과했습니다. 현재 검수는 이전 버전의 동일 의존성 환경을 재사용했으며 다른 OS의 네이티브 의존성 설치는 별도 확인이 필요합니다.

## 주요 흐름

- 내 성장: 분석 가설/6축을 누르면 해당 경험 노드·경로를 강조하고 원문 근거를 표시합니다.
- 경험 연결 지도: 6활동/7활동 간 관계. 근거 펼치기를 누르면 결과물 제목과 회고를 표시합니다.
- 6축 경험 렌즈: 반경은 축별 연결 경험 수 / 전체 경험 수. 능력 점수, 순위, 성격, 직업 적합성 수치가 아닙니다.
- 경험 아카이브: 갤러리/타임라인/필터와 경험 기록·회고·연결 근거 탭. 회고 도우미는 이 흐름 내부에 있습니다.
- 회고: 역할 → 행동/결과 → 배운 점, 편집 가능한 초안, 같은 경험에 별도 버전 저장. 원문은 자동으로 바꾸지 않습니다.
- 미저장 초안: 경험별로 메모리에 보관하여 내부 화면 이동 후 이어쓰기 가능합니다.
- 정정/삭제: 이전 확인 상태 해제, 관련 근거/노드/회고/초안/관계와 6축 수 갱신, 분석 상태 대기 표시.
- 활동 탐색: 필터/북마크/가상 조건, 과거 경험 → 탐색 가설 → 새 시도 제안의 연결 그래프.
- 데이터·설정: 공통 ETL와 비공개 분석 경계, 분석 상태만 시뮬레이션.

## 경계

실제 AI, 학교 API, 외부 모델 호출, 크롤러, 운영 DB, 영구 저장, 실제 자격/마감 확인, 동의/삭제 API는 연결하지 않습니다. 새로고침/데모 초기화 시 상태가 초기화됩니다. 가상 공고에 실제 원문 URL을 만들지 않습니다. 모델/추천 엔진은 미선정이고 비용/성능은 미실측입니다.

## 파일

- src/App.tsx: 상태·데이터·클릭 흐름과 SVG 시각화
- src/index.css: 스타일·반응형·동작 감소
- UX_REVIEW.md: 기획서 v0.3의 UX 결정과 구현 경계
- QA.json: 실제 로컬/Figma 검수 결과

Figma에서는 App.tsx가 src/app/App.tsx, 스타일이 src/styles/index.css에 위치하므로 CSS import만 ../styles/index.css로 조정했습니다. Figma 변환기 호환을 위해 JSX 자기 닫기 태그의 공백을 정규화했습니다.
